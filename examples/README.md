# Examples and reference data

The repository README documents the actual command interfaces and a conditional single-realization workflow. No redistributable end-to-end reference dataset was included in the original archive.

Before publishing a validated release, add a small input, a machine-readable configuration, expected outputs and a comparison script here. State units, binary layout, thread count, compiler and tolerances. Choose grid/ring limits consistent with the estimator; reducing a grid size alone is not sufficient.

Do not treat published paper figures in docs/figures as outputs generated by a packaged example. They illustrate the method and original published validation.
